### 第三步：确认需求文档（这是不可撤销的临界点）

AI会根据你的输入生成一份PRD，详细列出网站的功能、页面和设计风格，页面右侧可以完整预览。有要改的地方点“编辑文档”调整，没问题就点“确认生成应用”。

修改有两条路：可视化编辑模式里直接改文本、替换图片；或者继续跟AI对话下指令，比如“帮我把主题色换成绿色”。点右上角的分享图标，可以拿到临时预览链接或二维码，先发给同事朋友看看，再决定要不要发布。
